# Updating the ZEECO website

- Main website: `index.html`, `css/site.css`, `js/site.js`, images in `img/`.
- Pitch deck (13 slides): `deck/` (served at /deck/).
- Edit a file, then `git add -A && git commit -m "update" && git push`. Netlify redeploys automatically.
- `asset/` (design files) is git-ignored and never published.
